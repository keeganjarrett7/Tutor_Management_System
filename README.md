# Tutor Management System

A command-line tutor management application written in C that uses a linked list to store and manage tutor records.

## Features

- Add new tutors and their information
- Search for tutors based on tutoring preferences
- Delete tutor records
- Display the current list of tutors
- Prevent duplicate tutor entries
- Maintain tutor records using a linked-list data structure

## Concepts Used

- C
- Linked lists
- Structures
- Pointers
- Dynamic memory allocation
- Memory management with `malloc()` and `free()`
- User input validation

## Running the Program

Compile the program:

gcc main.c -o tutor_management

Run:

./tutor_management
